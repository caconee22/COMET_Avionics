# ROK2026

COMET ROK 2026 hardware project workspace.

## Projects

- `ROK_3`: Miniaturized ROK3 SMD-chip test board.
- `ROK_4`: ROK4 power-section design and small buck-converter research board.
- `Away_1`: Active avionics candidate version under development.

## Board Status

- `ROK_3`: Small-form-factor version using SMD chips. It was not used because
  of power-section issues, but it may still be recoverable and remains a test
  version.
- `ROK_4`: Further test version for power-section design. It is a research
  board for the small buck-converter power design.
- `Away_1`: The candidate avionics version intended for actual use. This is the
  current development target.

## Away_1

`Away_1` is the active candidate for the real avionics version.
It is currently under development.

The avionics design intent and development rules are documented in
`Away_1/README.md`.
